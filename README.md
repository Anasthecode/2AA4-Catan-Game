This is the repository for a Catan simulation made for the SFWRENG 2AA4 course at McMaster university. Currently, it runs a game between 3-4 agents
with randomized actions, following the invariants defined by the official Catan rules. It outputs the results of their actions to the command line,
keeping track of when agents recieve resources and build structures.
 
## Functionality of the program:
- Runs the setup phase of the game where each player places two settlements and roads
- Until either one player wins or the number of specified rounds have passed, the agents will roll the dice to generate resources and randomly place new structures
 
## Directories:
- `genai/src` This is some initial code generated by Claude, where we gave it the prompt "please turn this UML diagram into Java code." We mainly used this for brainstorming ideas for implementations, but is not the main code for the assignment
- `catan_game/src` Contains all of the code for the assignment. When pulling to test out the simulation this is the source code that should be compiled
- `catan_game/res` Contains the `config.properties` file where the main settings for the game are defined
